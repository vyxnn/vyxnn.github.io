*My capstone project for the Masters of IT, where the goal was to integrate an e-nose sensor with a Farmbot. I found this to be an interesting challenge as I had to learn Ruby on Rails and MQTT (a protocol for IoT devices) for development. Additionally, there were a lot of engineering tasks such as using a step-down regulator to build a customised power cable or developing a casing for the e-nose using CAD and 3D printers.*

### Full Technology Stack

Web application     
- **Database**: PostgreSQL     
- **Backend Framework**: Ruby on Rails       
- **Frontend Framework**: React, Redux, Typescript      

E-nose Sensor   
- **OS**: Linux   
- **Message Broker:** Rabbit MQ (MQTT)   
- **Script:** Python, MQTT  

Farmbot  
- **OS**: Farmbot OS (Elixir, Erlang)   
- **Firmware**: Arduino   
- **Hardware**: Built a power cable, 3D printed casing and wheels
